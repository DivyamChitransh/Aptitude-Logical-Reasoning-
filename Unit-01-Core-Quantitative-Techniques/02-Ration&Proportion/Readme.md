# Ratio and Proportion

## Introduction

Ratio and Proportion are important concepts in Quantitative Aptitude that help us compare quantities and understand the relationship between them.

A **ratio** compares two or more quantities, while a **proportion** states that two ratios are equal.

These concepts are commonly used in problems related to:

* Comparison of quantities
* Distribution
* Ages
* Mixtures
* Speed and distance
* Time and work
* Profit and loss
* Percentage-based problems

---

# 1. What is a Ratio?

A ratio is used to compare two quantities of the same kind.

It is represented using:

```text
a : b
```

This means the ratio of `a` to `b`.

For example:

If there are 10 boys and 15 girls in a class, then:

```text
Ratio of Boys : Girls

= 10 : 15

= 2 : 3
```

Therefore, the ratio of boys to girls is:

```text
2 : 3
```

---

# 2. Important Points About Ratio

Before comparing two quantities, both quantities should be in the **same unit**.

For example:

```text
2 meters : 50 centimeters
```

We cannot directly write:

```text
2 : 50
```

First, convert both quantities into the same unit.

```text
2 meters = 200 centimeters

Ratio = 200 : 50

= 4 : 1
```

---

# 3. Simplifying a Ratio

A ratio can be simplified by dividing both terms by their **Greatest Common Divisor (GCD)**.

### Example

Simplify:

```text
24 : 36
```

The GCD of 24 and 36 is 12.

Therefore:

```text
24 ÷ 12 : 36 ÷ 12

= 2 : 3
```

---

# 4. Equivalent Ratios

Ratios that represent the same relationship are called equivalent ratios.

For example:

```text
2 : 3
```

Multiply both terms by 2:

```text
4 : 6
```

Multiply both terms by 3:

```text
6 : 9
```

Therefore:

```text
2 : 3 = 4 : 6 = 6 : 9
```

All of these are equivalent ratios.

---

# 5. Dividing a Quantity in a Given Ratio

Suppose ₹600 has to be divided between A and B in the ratio:

```text
2 : 3
```

### Step 1: Find the total parts

```text
2 + 3 = 5
```

### Step 2: Find the value of one part

```text
600 / 5 = 120
```

### Step 3: Calculate each share

A's share:

```text
2 × 120 = ₹240
```

B's share:

```text
3 × 120 = ₹360
```

Therefore:

```text
A = ₹240
B = ₹360
```

---

# 6. What is Proportion?

When two ratios are equal, they are said to be in proportion.

It is represented as:

```text
a : b = c : d
```

or:

```text
a/b = c/d
```

For example:

```text
2 : 4 = 3 : 6
```

Because:

```text
2/4 = 1/2

3/6 = 1/2
```

Therefore:

```text
2 : 4 = 3 : 6
```

These ratios are in proportion.

---

# 7. Cross Multiplication in Proportion

If:

```text
a : b = c : d
```

Then:

```text
a × d = b × c
```

This is called **cross multiplication**.

### Example

Find the value of `x`.

```text
3 : 5 = x : 20
```

Using cross multiplication:

```text
3 × 20 = 5 × x

60 = 5x

x = 12
```

---

# 8. Fourth Proportional

If:

```text
a : b = c : x
```

Then `x` is called the **fourth proportional**.

Using cross multiplication:

```text
a × x = b × c

x = (b × c) / a
```

### Example

Find the fourth proportional to:

```text
2, 4 and 6
```

```text
2 : 4 = 6 : x

2x = 24

x = 12
```

Therefore, the fourth proportional is:

```text
12
```

---

# 9. Direct Proportion

Two quantities are in direct proportion when an increase in one quantity causes an increase in the other quantity.

Similarly, a decrease in one quantity causes a decrease in the other quantity.

### Example

If:

```text
1 notebook costs ₹20
```

Then:

```text
2 notebooks cost ₹40
3 notebooks cost ₹60
4 notebooks cost ₹80
```

As the number of notebooks increases, the total cost also increases.

Therefore:

```text
Number of notebooks ∝ Total cost
```

For direct proportion:

```text
x / y = constant
```

or:

```text
x₁ / y₁ = x₂ / y₂
```

### Example

If 5 notebooks cost ₹100, what is the cost of 8 notebooks?

```text
5 : 8 = 100 : x
```

```text
5x = 800

x = ₹160
```

---

# 10. Inverse Proportion

Two quantities are in inverse proportion when an increase in one quantity causes a decrease in the other quantity.

### Example

If more workers are assigned to complete the same work, fewer days are required.

```text
Workers ↑
Days ↓
```

Therefore:

```text
Workers ∝ 1 / Days
```

For inverse proportion:

```text
x × y = constant
```

or:

```text
x₁ × y₁ = x₂ × y₂
```

### Example

If 5 workers complete a job in 12 days, how many days will 10 workers take?

```text
5 × 12 = 10 × x

60 = 10x

x = 6 days
```

---

# 11. Continued Proportion

If three quantities `a`, `b`, and `c` are in continued proportion:

```text
a : b = b : c
```

Then:

```text
b² = a × c
```

### Example

If:

```text
4 : x = x : 36
```

Then:

```text
x² = 4 × 36

x² = 144

x = 12
```

Therefore:

```text
12
```

is the mean proportional.

---

# 12. Ratio-Based Comparison

Suppose:

```text
A : B = 2 : 3
```

This means:

```text
A = 2x
B = 3x
```

The actual values can be different.

For example:

```text
A = 20
B = 30
```

or:

```text
A = 200
B = 300
```

But the relationship remains:

```text
2 : 3
```

---

# 13. Combining Ratios

Suppose:

```text
A : B = 2 : 3
```

and:

```text
B : C = 4 : 5
```

To find:

```text
A : B : C
```

First make the common value of `B` equal.

The LCM of 3 and 4 is 12.

Multiply:

```text
A : B = 2 : 3

= 8 : 12
```

And:

```text
B : C = 4 : 5

= 12 : 15
```

Therefore:

```text
A : B : C = 8 : 12 : 15
```

---

# 14. Ratio and Percentage

Ratio can also be converted into a percentage.

Suppose:

```text
A : B = 2 : 3
```

Total parts:

```text
2 + 3 = 5
```

Percentage of A:

```text
(2 / 5) × 100 = 40%
```

Percentage of B:

```text
(3 / 5) × 100 = 60%
```

Therefore:

```text
A = 40%
B = 60%
```

# 16. Important Shortcuts and Tips

### Tip 1: Always Convert Units First

Before finding a ratio:

```text
2 kg : 500 g
```

Convert:

```text
2 kg = 2000 g
```

Therefore:

```text
2000 : 500

= 4 : 1
```

---

### Tip 2: Use Variables for Ratio Problems

If:

```text
A : B = 3 : 5
```

Assume:

```text
A = 3x
B = 5x
```

This makes it easier to solve word problems.

---

### Tip 3: Find Total Parts Before Distribution

If a quantity is divided in the ratio:

```text
a : b
```

Then:

```text
Total Parts = a + b
```

Value of one part:

```text
Total Quantity / (a + b)
```

---

### Tip 4: Identify Direct or Inverse Proportion

Ask:

```text
If one quantity increases,
what happens to the other quantity?
```

If both increase/decrease together:

```text
Direct Proportion
```

If one increases and the other decreases:

```text
Inverse Proportion
```

---

# 17. Common Mistakes

* Comparing quantities without converting them into the same unit.
* Confusing ratio with actual values.
* Using addition instead of multiplication in inverse proportion.
* Applying direct proportion when the quantities are inversely related.
* Forgetting to simplify the final ratio.
* Not making the common term equal while combining ratios.

---

# 18. Summary

* A **ratio** compares two quantities.
* A **proportion** states that two ratios are equal.
* Quantities should be converted into the same unit before finding their ratio.
* Direct proportion means both quantities change in the same direction.
* Inverse proportion means one quantity increases while the other decreases.
* Cross multiplication is commonly used to solve proportion problems.
* Ratio and Proportion are widely used in quantitative aptitude and real-life calculation problems.
