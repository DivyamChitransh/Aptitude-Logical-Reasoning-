# Average

## Introduction

Average is a method used to represent a group of values with a single value.

It gives us an idea of the **central or typical value** of a set of numbers.

For example, suppose the marks of 5 students are:

```text
60, 70, 80, 90, 100
```

Instead of looking at every student's marks separately, we can find one value that represents the overall performance.

```text
Average = (60 + 70 + 80 + 90 + 100) / 5

Average = 400 / 5

Average = 80
```

Therefore, the average marks are **80**.

---

# 1. Basic Formula of Average

The basic formula is:

```text
Average = Sum of All Values / Total Number of Values
```

Or:

```text
Average = Total / Number of Items
```

### Example

Find the average of:

```text
10, 20, 30, 40, 50
```

```text
Sum = 10 + 20 + 30 + 40 + 50

Sum = 150

Number of values = 5

Average = 150 / 5

Average = 30
```

---

# 2. Finding the Total Using Average

Sometimes the average and the number of values are given, and we need to find the total.

Formula:

```text
Total = Average × Number of Values
```

### Example

The average marks of 20 students is 65. Find the total marks.

```text
Total = Average × Number of Students

= 65 × 20

= 1300
```

Therefore, the total marks are **1300**.

---

# 3. Finding a Missing Number

If the average of a group of numbers is given and one value is missing, we can first find the total sum.

### Example

The average of 5 numbers is 24.

Four of the numbers are:

```text
20, 22, 25, 28
```

Find the fifth number.

### Step 1: Find the total

```text
Total = Average × Number of Values

= 24 × 5

= 120
```

### Step 2: Find the sum of known numbers

```text
20 + 22 + 25 + 28 = 95
```

### Step 3: Find the missing number

```text
Missing Number = 120 - 95

= 25
```

---

# 4. Adding a New Value

When a new value is added, the number of values changes.

### Example

The average of 10 students is 60.

A new student joins the group and has scored 80 marks.

Find the new average.

### Step 1: Find the original total

```text
Total = 10 × 60

= 600
```

### Step 2: Add the new value

```text
New Total = 600 + 80

= 680
```

### Step 3: Find the new average

```text
New Average = 680 / 11

= 61.82
```

Therefore, the new average is approximately **61.82**.

---

# 5. Removing a Value

When a value is removed, the total number of values decreases.

### Example

The average of 8 numbers is 25.

One number, 32, is removed.

Find the new average.

### Step 1: Find the original total

```text
Total = 25 × 8

= 200
```

### Step 2: Remove the value

```text
New Total = 200 - 32

= 168
```

### Step 3: Find the new average

```text
New Average = 168 / 7

= 24
```

Therefore, the new average is **24**.

---

# 6. Replacement of a Value

Sometimes one value is replaced by another value.

In this case, the number of items remains the same.

### Example

The average of 10 students is 50.

One student's marks, 40, are replaced by 70.

Find the new average.

### Step 1: Find the original total

```text
Original Total = 10 × 50

= 500
```

### Step 2: Find the change in marks

```text
Change = 70 - 40

= 30
```

### Step 3: Find the new total

```text
New Total = 500 + 30

= 530
```

### Step 4: Find the new average

```text
New Average = 530 / 10

= 53
```

Therefore, the new average is **53**.

---

# 7. Change in Average

If every value in a group increases or decreases by the same amount, the average also changes by the same amount.

### Example

The average marks of a class are 65.

If every student's marks increase by 5 marks:

```text
New Average = 65 + 5

= 70
```

Similarly, if every value decreases by 3:

```text
New Average = 65 - 3

= 62
```

### Important Rule

```text
If every value changes by x,
the average also changes by x.
```

---

# 8. Combined Average

Combined average is used when two or more groups are combined.

Formula:

```text
Combined Average =
(Total of Group 1 + Total of Group 2) /
(Total Number of Items)
```

### Example

The average marks of 20 students is 60.

The average marks of another 30 students is 70.

Find the combined average.

### Step 1: Find the total marks of each group

```text
Group 1 Total = 20 × 60

= 1200
```

```text
Group 2 Total = 30 × 70

= 2100
```

### Step 2: Find the combined total

```text
Combined Total = 1200 + 2100

= 3300
```

### Step 3: Find the combined average

```text
Combined Average = 3300 / 50

= 66
```

Therefore, the combined average is **66**.

---

# 9. Weighted Average

A weighted average is used when different values have different importance or frequencies.

Formula:

```text
Weighted Average =
Σ(Value × Weight) / ΣWeights
```

### Example

A student scores:

```text
Subject A = 80 marks with weight 2

Subject B = 60 marks with weight 3
```

Find the weighted average.

```text
Weighted Average =
(80 × 2 + 60 × 3) / (2 + 3)

= (160 + 180) / 5

= 340 / 5

= 68
```

Therefore, the weighted average is **68**.

---

# 10. Average Speed

Average is also used in speed-related problems.

The basic formula is:

```text
Average Speed =
Total Distance / Total Time
```

### Example

A car travels:

```text
60 km in 1 hour
```

and then:

```text
120 km in 2 hours
```

Find the average speed.

```text
Total Distance = 60 + 120

= 180 km
```

```text
Total Time = 1 + 2

= 3 hours
```

Therefore:

```text
Average Speed = 180 / 3

= 60 km/h
```

---

# 11. Shortcut for Consecutive Numbers

The average of consecutive numbers is often easy to find.

### Example

Find the average of:

```text
11, 12, 13, 14, 15
```

Since the numbers are equally spaced, the average is the middle number:

```text
Average = 13
```

For an arithmetic sequence:

```text
Average = (First Term + Last Term) / 2
```

### Example

Find the average of:

```text
10, 20, 30, 40, 50
```

```text
Average = (10 + 50) / 2

= 30
```

# 14. Important Formulas

## Basic Average

```text
Average = Sum of Values / Number of Values
```

## Finding Total

```text
Total = Average × Number of Values
```

## Combined Average

```text
Combined Average =
(n₁ × Average₁ + n₂ × Average₂) / (n₁ + n₂)
```

## Average of Consecutive Numbers

```text
Average = (First Number + Last Number) / 2
```

## Average Speed

```text
Average Speed = Total Distance / Total Time
```

---

# 15. Important Shortcuts and Tips

### Tip 1: Convert Average into Total

Whenever an average question gives the number of items, first calculate the total.

```text
Total = Average × Number of Items
```

This makes most aptitude questions easier.

---

### Tip 2: Adding or Removing One Value

Remember that when a value is added or removed:

```text
Total changes
AND
Number of items also changes
```

Students often change only the total and forget to update the number of items.

---

### Tip 3: Replacement Questions

When one value is replaced:

```text
New Total =
Old Total - Removed Value + New Value
```

The number of values remains the same.

---

### Tip 4: Combined Average

Never simply add two averages and divide by 2 unless both groups contain the same number of items.

For example:

```text
Average of 10 students = 60

Average of 30 students = 80
```

The combined average is **not**:

```text
(60 + 80) / 2 = 70
```

You must consider the number of students in each group.

---

### Tip 5: Consecutive Numbers

For equally spaced numbers:

```text
Average = (First + Last) / 2
```

No need to add every number individually.

---

# 16. Common Mistakes

* Dividing by the wrong number of items.
* Forgetting to update the number of values after adding or removing an item.
* Taking the simple average of group averages without considering group sizes.
* Confusing average speed with the average of two speeds.
* Forgetting to convert the average into total when solving word problems.
* Making calculation errors while finding missing values.

---

# 17. Summary

* Average represents a group of values using a single value.
* The basic formula is:

```text
Average = Total / Number of Items
```

* To find the total:

```text
Total = Average × Number of Items
```

* Adding or removing values changes both the total and the number of items.
* In replacement problems, the number of items remains the same.
* Combined average depends on both the averages and the number of items in each group.
* The average of equally spaced numbers can be found using:

```text
Average = (First + Last) / 2
```

* Average speed is calculated using total distance divided by total time.
