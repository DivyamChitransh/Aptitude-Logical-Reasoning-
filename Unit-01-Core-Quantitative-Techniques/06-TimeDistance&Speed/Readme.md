# Time, Speed and Distance

## Introduction

Time, Speed and Distance is an important topic in Quantitative Aptitude.

This topic is based on the relationship between:

* Distance
* Speed
* Time

Many real-life situations can be solved using these concepts, such as:

* Travelling from one place to another.
* Finding the time required to reach a destination.
* Comparing the speeds of two vehicles.
* Problems related to trains.
* Problems related to boats and streams.
* Relative speed problems.
* Average speed problems.

The basic relationship is:

```text
Distance = Speed × Time
```

---

# 1. Basic Formula

The three main formulas are:

```text
Distance = Speed × Time
```

```text
Speed = Distance / Time
```

```text
Time = Distance / Speed
```

### Example

A car travels 120 km in 2 hours.

Find its speed.

```text
Speed = Distance / Time

Speed = 120 / 2

Speed = 60 km/hr
```

Therefore, the speed of the car is **60 km/hr**.

---

# 2. Units of Speed, Distance and Time

The commonly used units are:

| Quantity | Common Units            |
| -------- | ----------------------- |
| Distance | km, metres              |
| Time     | hours, minutes, seconds |
| Speed    | km/hr, m/s              |

It is important to keep the units consistent.

For example:

```text
Distance = km
Time = hours

Speed = km/hr
```

Or:

```text
Distance = metres
Time = seconds

Speed = m/s
```

---

# 3. Conversion Between km/hr and m/s

### Convert km/hr to m/s

```text
Speed in m/s = Speed in km/hr × 5/18
```

### Convert m/s to km/hr

```text
Speed in km/hr = Speed in m/s × 18/5
```

### Example 1

Convert 72 km/hr into m/s.

```text
72 × 5/18

= 20 m/s
```

### Example 2

Convert 20 m/s into km/hr.

```text
20 × 18/5

= 72 km/hr
```

---

# 4. Relationship Between Speed and Time

For the same distance:

```text
Speed ∝ 1 / Time
```

This means:

```text
More Speed → Less Time

Less Speed → More Time
```

### Example

A person travels the same distance.

At 60 km/hr, the journey takes 4 hours.

If the speed becomes 80 km/hr:

```text
Speed Ratio = 60 : 80

= 3 : 4
```

Since time is inversely proportional:

```text
Time Ratio = 4 : 3
```

Therefore:

```text
New Time = 4 × 3/4

= 3 hours
```

---

# 5. Relative Speed

Relative speed is used when two objects are moving.

## Moving in the Same Direction

When two objects move in the same direction:

```text
Relative Speed = Difference of Speeds
```

### Example

Car A = 80 km/hr

Car B = 60 km/hr

Both move in the same direction.

```text
Relative Speed = 80 - 60

= 20 km/hr
```

---

## Moving in Opposite Directions

When two objects move towards each other or in opposite directions:

```text
Relative Speed = Sum of Speeds
```

### Example

Car A = 60 km/hr

Car B = 40 km/hr

```text
Relative Speed = 60 + 40

= 100 km/hr
```

---

# 6. Average Speed

Average speed is:

```text
Average Speed = Total Distance / Total Time
```

### Example

A person travels:

* 60 km in 1 hour.
* 40 km in 1 hour.

```text
Total Distance = 60 + 40

= 100 km
```

```text
Total Time = 1 + 1

= 2 hours
```

Therefore:

```text
Average Speed = 100 / 2

= 50 km/hr
```

---

# 7. Average Speed for Equal Distances

When equal distances are travelled at two different speeds:

```text
Average Speed = 2xy / (x + y)
```

Where:

```text
x = First Speed

y = Second Speed
```

### Example

A person travels equal distances at:

```text
Speed 1 = 40 km/hr

Speed 2 = 60 km/hr
```

```text
Average Speed = (2 × 40 × 60) / (40 + 60)

= 4800 / 100

= 48 km/hr
```

Therefore, the average speed is **48 km/hr**.

---

# 8. Percentage Change in Speed and Time

Since speed and time are inversely proportional:

```text
Speed Increases → Time Decreases

Speed Decreases → Time Increases
```

## When Speed Increases

If speed increases by `x%`:

```text
Decrease in Time = x / (100 + x) × 100
```

### Example

If speed increases by 25%:

```text
Decrease in Time = 25 / 125 × 100

= 20%
```

---

## When Speed Decreases

If speed decreases by `x%`:

```text
Increase in Time = x / (100 - x) × 100
```

### Example

If speed decreases by 20%:

```text
Increase in Time = 20 / 80 × 100

= 25%
```

# 9. Train Problems

Train problems are based on the same concept:

```text
Distance = Speed × Time
```

However, the distance covered by a train depends on what it is crossing.

## Train Crossing a Pole or Person

The train covers only its own length.

```text
Time = Length of Train / Speed
```

### Example

A train is 200 metres long and moves at 20 m/s.

```text
Time = 200 / 20

= 10 seconds
```

---

## Train Crossing a Platform

The train covers:

```text
Length of Train + Length of Platform
```

Therefore:

```text
Time = (Train Length + Platform Length) / Speed
```

### Example

Train length = 150 m

Platform length = 250 m

Speed = 20 m/s

```text
Distance = 150 + 250

= 400 m
```

```text
Time = 400 / 20

= 20 seconds
```

---

## Two Trains Crossing Each Other

### Moving in Opposite Directions

```text
Relative Speed = Speed 1 + Speed 2
```

Distance covered:

```text
Length of Train 1 + Length of Train 2
```

Therefore:

```text
Time = Total Length / Relative Speed
```

### Moving in the Same Direction

```text
Relative Speed = Speed 1 - Speed 2
```

---

# 10. Boats and Streams

In boat and stream problems:

* Downstream → Boat moves with the stream.
* Upstream → Boat moves against the stream.

## Formulas

```text
Downstream Speed = Boat Speed + Stream Speed
```

```text
Upstream Speed = Boat Speed - Stream Speed
```

If upstream and downstream speeds are given:

```text
Boat Speed = (Downstream + Upstream) / 2
```

```text
Stream Speed = (Downstream - Upstream) / 2
```

### Example

Downstream speed = 15 km/hr

Upstream speed = 9 km/hr

Boat speed:

```text
(15 + 9) / 2

= 12 km/hr
```

Stream speed:

```text
(15 - 9) / 2

= 3 km/hr
```

---

# 11. Problems Based on Meeting

Suppose two people start from two different places and move towards each other.

If:

```text
Distance = D

Speed of A = x

Speed of B = y
```

Then:

```text
Time to Meet = D / (x + y)
```

Because their relative speed is:

```text
x + y
```

### Example

Two cities are 300 km apart.

A travels at 60 km/hr.

B travels at 40 km/hr towards A.

```text
Relative Speed = 60 + 40

= 100 km/hr
```

Therefore:

```text
Time = 300 / 100

= 3 hours
```

They meet after **3 hours**.

---

# 12. Problems Based on Overtaking

When two objects move in the same direction:

```text
Relative Speed = Faster Speed - Slower Speed
```

### Example

A car travels at 80 km/hr.

Another car travels at 60 km/hr.

The distance between them is 40 km.

```text
Relative Speed = 80 - 60

= 20 km/hr
```

Therefore:

```text
Time to Catch = 40 / 20

= 2 hours
```

# 14. Common Mistakes

### Mistake 1: Not Converting Units

Always make sure the units match.

For example:

```text
Speed = km/hr

Distance = metres
```

You must convert one of them before calculating.

---

### Mistake 2: Adding Speeds in the Same Direction

For the same direction:

```text
Relative Speed = Difference
```

Not addition.

---

### Mistake 3: Using Simple Average for Equal Distances

For equal distances, this is usually incorrect:

```text
(40 + 60) / 2 = 50
```

The correct formula is:

```text
2xy / (x + y)
```

For 40 km/hr and 60 km/hr:

```text
2 × 40 × 60 / 100

= 48 km/hr
```

---

### Mistake 4: Forgetting Train Length

While crossing a platform or another train, include all relevant lengths.

---

### Mistake 5: Confusing Upstream and Downstream

Remember:

```text
Downstream → Add stream speed

Upstream → Subtract stream speed
```
