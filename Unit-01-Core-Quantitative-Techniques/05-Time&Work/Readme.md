# Time and Work

## Introduction

Time and Work is an important topic in Quantitative Aptitude.

In these questions, we generally calculate:

* How much time a person takes to complete a work.
* How much work is completed in a given time.
* How multiple people can work together.
* How efficiency affects the time required to complete a task.
* Problems related to pipes and cisterns.

The main relationship between **Work, Time, and Efficiency** is:

```text
Work = Efficiency × Time
```

This means that the amount of work completed depends on how efficiently a person works and how much time they spend working.

---

# 1. Basic Concept of Work

Suppose a person can complete a work in **10 days**.

This means:

```text
Work completed in 10 days = 1 complete work
```

Therefore, work completed in 1 day is:

```text
1 / 10
```

This is called the **one-day work**.

### Formula

```text
One Day Work = 1 / Total Number of Days
```

### Example

If A can complete a work in 5 days:

```text
A's 1 day work = 1 / 5
```

If B can complete the same work in 10 days:

```text
B's 1 day work = 1 / 10
```

This means A completes more work in one day, so A is more efficient than B.

---

# 2. Work Done in a Given Number of Days

If a person completes a work in `x` days:

```text
One Day Work = 1 / x
```

Therefore, work completed in `n` days is:

```text
Work Done = n / x
```

### Example

A can complete a work in 12 days.

Find the work completed by A in 4 days.

```text
One Day Work = 1 / 12

Work in 4 days = 4 × 1/12

= 1/3
```

Therefore, A completes **one-third of the work** in 4 days.

---

# 3. Time Required to Complete Work

If a person completes `1/x` part of the work in one day:

```text
Time Required = 1 / One Day Work
```

### Example

A completes:

```text
1/8
```

of a work in one day.

Therefore:

```text
Time Required = 8 days
```

---

# 4. Two People Working Together

Suppose:

* A can complete a work in `x` days.
* B can complete the same work in `y` days.

Their one-day work is:

```text
A = 1/x

B = 1/y
```

Together:

```text
A + B = 1/x + 1/y
```

Therefore:

```text
Time Taken Together = xy / (x + y)
```

### Example

A can complete a work in 10 days.

B can complete the same work in 15 days.

### Step 1: Find one-day work

```text
A = 1/10

B = 1/15
```

### Step 2: Add their work

```text
A + B = 1/10 + 1/15

= 3/30 + 2/30

= 5/30

= 1/6
```

Together, they complete:

```text
1/6 of the work per day
```

Therefore, total time required is:

```text
6 days
```

---

# 5. Shortcut for Two People

If A completes work in `x` days and B completes it in `y` days:

```text
Time Together = xy / (x + y)
```

### Example

A = 12 days

B = 18 days

```text
Time = (12 × 18) / (12 + 18)

= 216 / 30

= 7.2 days
```

---

# 6. Three People Working Together

Suppose:

* A completes work in `a` days.
* B completes work in `b` days.
* C completes work in `c` days.

Their combined one-day work is:

```text
1/a + 1/b + 1/c
```

Then:

```text
Time = 1 / Combined One Day Work
```

### Example

A can complete a work in 12 days.

B can complete it in 18 days.

C can complete it in 36 days.

```text
A = 1/12

B = 1/18

C = 1/36
```

Taking LCM = 36:

```text
A + B + C

= 3/36 + 2/36 + 1/36

= 6/36

= 1/6
```

Therefore, all three together complete the work in:

```text
6 days
```

---

# 7. Efficiency and Time

Efficiency and time are inversely proportional.

```text
More Efficiency → Less Time

Less Efficiency → More Time
```

Formula:

```text
Efficiency ∝ 1 / Time
```

Therefore:

```text
Efficiency Ratio = Inverse of Time Ratio
```

### Example

A completes a work in 10 days.

B completes the same work in 15 days.

Their efficiency ratio is:

```text
A : B = 15 : 10

= 3 : 2
```

Therefore, A is more efficient than B.

---

# 8. Work and Efficiency Ratio

If:

```text
A : B efficiency = 2 : 3
```

Then their work done in the same amount of time is also:

```text
2 : 3
```

However, the time required to complete the same work is the inverse:

```text
Time Ratio = 3 : 2
```

### Important Rule

```text
Efficiency Ratio = Work Ratio
                 (when time is same)

Efficiency Ratio = Inverse of Time Ratio
                 (when work is same)
```

---

# 9. Using LCM Method

The LCM method is useful for solving Time and Work problems without fractions.

### Example

A completes a work in 12 days.

B completes the same work in 18 days.

Take:

```text
Total Work = LCM of 12 and 18

= 36 units
```

Therefore:

```text
A's 1 day work = 36 / 12

= 3 units
```

```text
B's 1 day work = 36 / 18

= 2 units
```

Together:

```text
Work per day = 3 + 2

= 5 units
```

Therefore:

```text
Time = 36 / 5

= 7.2 days
```

---

# 10. Work Done by Different People

### Example

A can complete a work in 10 days.

B can complete it in 15 days.

A works alone for 2 days. Then B joins A.

Find the total time required.

### Step 1: Work completed by A in 2 days

```text
A's 1 day work = 1/10

Work in 2 days = 2/10

= 1/5
```

Remaining work:

```text
1 - 1/5

= 4/5
```

### Step 2: Work done together

```text
A + B = 1/10 + 1/15

= 1/6
```

Time for remaining work:

```text
(4/5) ÷ (1/6)

= 24/5

= 4.8 days
```

Therefore, total time:

```text
2 + 4.8

= 6.8 days
```

---

# 11. One Person Leaves the Work

Sometimes multiple people start working together and one person leaves after a few days.

### Example

A and B can complete a work in 12 days and 18 days respectively.

They work together for 3 days, after which B leaves.

Find the total time required if A completes the remaining work.

### Step 1: Combined one-day work

```text
1/12 + 1/18

= 5/36
```

### Step 2: Work completed in 3 days

```text
3 × 5/36

= 5/12
```

Remaining work:

```text
1 - 5/12

= 7/12
```

### Step 3: A completes the remaining work

A's one-day work:

```text
1/12
```

Time required:

```text
(7/12) ÷ (1/12)

= 7 days
```

Therefore:

```text
Total Time = 3 + 7

= 10 days
```

---

# 12. Men and Days

Some Time and Work questions involve the number of workers.

The basic relationship is:

```text
Work = Number of Workers × Number of Days × Efficiency
```

If efficiency is the same:

```text
Men × Days = Constant
```

### Example

10 workers can complete a work in 12 days.

How many workers are required to complete the same work in 8 days?

```text
10 × 12 = x × 8
```

```text
x = 120 / 8

= 15
```

Therefore, **15 workers** are required.

---

# 13. Men, Days and Hours

When the number of working hours also changes:

```text
Work = Men × Days × Hours × Efficiency
```

### Example

10 workers working 8 hours per day can complete a work in 15 days.

How many workers are required to complete the same work in 10 days if they work 12 hours per day?

```text
10 × 15 × 8 = x × 10 × 12
```

```text
1200 = 120x
```

```text
x = 10
```

Therefore, **10 workers** are required.

---

# 14. Pipes and Cisterns

Pipes and Cisterns problems are solved using the same concept as Time and Work.

* An inlet pipe fills the tank → Positive work.
* An outlet pipe empties the tank → Negative work.

### Example

Pipe A can fill a tank in 10 hours.

Pipe B can empty the tank in 15 hours.

Net work in one hour:

```text
1/10 - 1/15

= 3/30 - 2/30

= 1/30
```

Therefore, the tank will be filled in:

```text
30 hours
```

---

# 15. Important Formulas

## One Day Work

```text
One Day Work = 1 / Total Days
```

## Work Done

```text
Work Done = Number of Days × One Day Work
```

## Time Required

```text
Time = Total Work / Work Done Per Day
```

## Two People Working Together

```text
Time = xy / (x + y)
```

## Efficiency and Time

```text
Efficiency ∝ 1 / Time
```

## Men and Days

```text
Men × Days = Constant
```

## Men, Days and Hours

```text
Men × Days × Hours × Efficiency = Constant
```

---

# 16. Important Shortcuts and Tips

### Tip 1: Use the LCM Method

Instead of dealing with fractions, take the LCM of the number of days as the total work.

For example:

```text
A = 12 days

B = 18 days

Total Work = LCM(12, 18)

= 36 units
```

Then:

```text
A = 3 units/day

B = 2 units/day
```

This makes calculations easier.

---

### Tip 2: Faster Worker Has Greater Efficiency

If A takes fewer days than B:

```text
A is more efficient than B
```

For example:

```text
A = 10 days

B = 20 days
```

Efficiency ratio:

```text
A : B = 20 : 10

= 2 : 1
```

---

### Tip 3: Work and Time Are Inversely Proportional

For the same work:

```text
More Workers → Less Time

Fewer Workers → More Time
```

Similarly:

```text
More Efficiency → Less Time

Less Efficiency → More Time
```

---

### Tip 4: Pipes That Empty Are Negative

While solving Pipes and Cisterns questions:

```text
Filling Pipe = +

Emptying Pipe = -
```

Always subtract the work done by an outlet pipe.

---

# 17. Common Mistakes

* Adding the number of days directly instead of adding one-day work.
* Forgetting that efficiency and time are inversely proportional.
* Treating an outlet pipe as positive work.
* Forgetting to calculate the remaining work when a worker joins or leaves.
* Ignoring working hours in Men-Days-Hours problems.
* Using averages instead of total work in work-rate problems.

---

# 18. Summary

The most important concept in Time and Work is:

```text
One Day Work = 1 / Total Time
```

For multiple people:

```text
Combined Work =
Individual Work Rates Added Together
```

For the same amount of work:

```text
Efficiency ↑ → Time ↓

Efficiency ↓ → Time ↑
```

For workers:

```text
Work = Men × Days × Hours × Efficiency
```

And for pipes:

```text
Inlet = Positive Work

Outlet = Negative Work
```

Understanding **one-day work** and the **LCM method** makes most Time and Work aptitude problems much easier.
